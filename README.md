# 🚀 Exercicios em Python

Este repositório contém a resolução de uma lista de exercícios práticos desenvolvidos em **Python**. O objetivo das atividades foi aplicar conceitos fundamentais de lógica de programação, manipulação de estruturas de dados e controle de fluxo.

---

## 📋 Resumo das Atividades Desenvolvidas

| Atividade | Título | O que o script faz |
| :--- | :--- | :--- |
| **Exercício 1** | Identificador de Pares e Ímpares | Percorre um intervalo fixo de 0 a 100 para identificar e listar quais números são pares e quais são ímpares. |
| **Exercício 2** | Análise de Extremos Numéricos | Recebe três valores numéricos do usuário, armazena-os em uma lista e exibe qual é o maior e o menor valor entre eles. |
| **Exercício 3** | Efeito de Escada com Texto | Recebe um nome informado pelo usuário e o exibe de forma progressiva (letra por letra), criando um efeito visual vertical de escada. |
| **Exercício 4** | Gerador da Série de Fibonacci | Calcula e exibe a sequência matemática de Fibonacci de forma dinâmica até o enésimo ($n$-ésimo) termo definido pelo usuário. |
| **Exercício 5** | Validador de Dados Cadastrais | Lê e valida informações de perfil (nome, idade, salário, sexo e estado civil), repetindo a solicitação até que todas as regras de validação sejam atendidas. |
| **Exercício 6** | Teste de Números Primos | Avalia se um número inteiro digitado pelo usuário é ou não um número primo com base nos restos de divisões inteiras. |
| **Exercício 7** | Calculadora de Fatorial | Calcula e exibe o resultado fatorial de um número inteiro inserido pelo usuário através de multiplicações consecutivas. |
| **Exercício 8** | Análise Estatística de Vetores | Varre uma lista numérica predefinida para retornar seu tamanho, maior/menor valor, somatória e exibi-la em ordens crescente e decrescente. |
| **Exercício 9** | Representação de Tabela por Dicionário | Converte dados estruturados em formato de tabela para um modelo de dicionário nativo do Python, otimizando o mapeamento de chaves e valores. |
| **Exercício 10** | Autenticação com Controle de Acesso | Simula uma tela de login que barra o usuário repetidamente, liberando o acesso apenas quando a senha numérica exata é digitada. |
| **Exercício 11** | Gerador Automatizado de Tabuada | Solicita ao usuário um número de 1 a 10 e gera instantaneamente a tabuada completa correspondente (multiplicações de 1 a 10). |

---

## 🛠️ Tecnologias e Conceitos Aplicados

* **Estruturas de Repetição:** `for` e `while`
* **Estruturas Condicionais:** `if`, `elif`, `else`
* **Estruturas de Dados:** Listas e Dicionários
* **Operadores Aritméticos e Lógicos**
* **Manipulação de Textos (Strings)**
